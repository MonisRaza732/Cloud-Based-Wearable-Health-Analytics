# Cloud-Based Wearable Health Analytics Platform using Edge-Cloud Intelligence

## Project Overview

This project proposes a smart healthcare monitoring system that combines wearable devices, edge computing, and cloud computing to provide real-time health analytics. The platform continuously collects physiological data from wearable sensors, performs preliminary processing at the edge, and stores and analyzes data in the cloud for remote monitoring and intelligent decision-making.

## Problem Statement

Healthcare monitoring systems relying solely on cloud computing often experience higher latency, increased bandwidth usage, and slower emergency response times. There is a need for an intelligent healthcare platform that performs local processing on edge devices while leveraging cloud resources for long-term analytics and storage.

---

## Objectives

- Monitor patient health in real time.
- Reduce latency using edge computing.
- Detect abnormal health conditions using AI.
- Store historical health records securely in the cloud.
- Provide dashboards for patients and doctors.
- Generate emergency alerts.
- Ensure secure communication between devices.
