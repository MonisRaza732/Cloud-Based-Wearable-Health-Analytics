# Problem Statement

Wearable devices generate a continuous stream of physiological data such as heart rate, blood oxygen level, ECG, body temperature, and physical activity. Traditional cloud-based healthcare systems often suffer from high latency and increased bandwidth usage because all sensor data is transmitted directly to cloud servers.

The objective of this project is to design an intelligent health analytics platform where wearable devices send data to nearby edge devices. The edge layer performs data filtering and preliminary analysis before forwarding relevant information to the cloud. This approach improves response time, reduces network traffic, and enables efficient remote healthcare monitoring.
